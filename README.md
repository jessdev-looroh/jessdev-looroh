## 🔥 Proyectos Destacados

### 🍽️ **QeHay — Ecosistema para Restaurantes**

Plataforma modular para gestión completa de restaurantes: menú, pedidos, cocina, notificaciones, autenticación y motor de IA.

**Stack:**  
NestJS • FastAPI • React • Flutter • PostgreSQL • DynamoDB • NATS • AWS (SNS/SQS/Lambda) • GCP (GKE/Helm/Cloud Build)

**Módulos principales:**

- `auth-ms` — Autenticación híbrida online/offline  
- `orders-ms` — Sistema de pedidos en tiempo real  
- `products-ms` — Catálogo, recetas, complementos  
- `payments-ms` — Integración con pasarelas y sesiones de pago  
- `client-gateway` — API Gateway y orquestación  
- `qeai-sdk` — SDK interno compartido con tipados y utilidades
